# Qoodish for Android

The Android app published on Google Play. It is a
[Trusted Web Activity](https://developer.chrome.com/docs/android/trusted-web-activity)
that opens https://qoodish.com in Chrome without browser UI, generated by
[Bubblewrap](https://github.com/GoogleChromeLabs/bubblewrap). Every change
to the web app reaches the Android app without a new release; only changes
to `twa-manifest.json` need one.

## Files

`twa-manifest.json` is the source of the project. Everything else in this
directory is generated from it by Bubblewrap, so do not edit it by hand:
change `twa-manifest.json` and regenerate.

`android.keystore`, the upload key, is kept out of the repository. Google
Play signs the published app with its own app signing key.

## Setup

```bash
npm i -g @bubblewrap/cli
bubblewrap doctor
```

On first run Bubblewrap offers to install a JDK and the Android SDK.

## Building

```bash
bubblewrap build
```

The first build offers to create `android.keystore` when it is missing. Set
`BUBBLEWRAP_KEYSTORE_PASSWORD` and `BUBBLEWRAP_KEY_PASSWORD` to build
without the password prompts. The build writes `app-release-bundle.aab`
for Google Play and `app-release-signed.apk` for installing on a device:

```bash
adb install app-release-signed.apk
```

## Releasing

1. Run `bubblewrap update` to bump `appVersionCode` and `appVersionName`
   and regenerate the project from `twa-manifest.json`.
2. Build, and upload `app-release-bundle.aab` to the Play Console.

## Digital Asset Links

The app hides the browser UI only when https://qoodish.com/.well-known/assetlinks.json
lists the SHA-256 fingerprints of the keys that sign it. Add both the app
signing key from the Play Console (Test and release > App integrity) and
the upload key. Each `add` records the fingerprint in `twa-manifest.json`
and rewrites the file the web app serves:

```bash
bubblewrap fingerprint add <SHA-256 fingerprint> --name=<key> --output=../public/.well-known/assetlinks.json
```
